# CMC:PE
cmc:pe é uma recriação do minecraft em PaperScript, facil de instalar e gasta 8 páginas de um caderno seu com folhas a5.

## Fácil para instalar
requesitos:
- um caderno com paginas a5 com 9 páginas restantes, 8 para instalar e 1 para dar espaço para outras coisas que tu quiser.
- um lápis hb com ponta (tem que ultilizar para também poder jogar)
- uma borracha (quanto melhor e quanto apagar mais rapido mais fps.)
- você (para instalar e fazer o jogo funcionar)
